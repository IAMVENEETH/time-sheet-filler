    Accepted formats

    JSON keyed by date. Durations can be "minutes": 105, "hours": "1:45" or "duration": "1 hr 45 min". Description is optional (the title is used).

    {
  "2026-09-21": [
    { "category": "Internal Meeting", "duration": "45 min",
      "title": "Daily Standup", "description": "..." }
  ]
}

    Or the plain-text weekly format with Monday — 21 Sep day headers, Category — 1 hr 45 min lines, then Title: and Description:.
